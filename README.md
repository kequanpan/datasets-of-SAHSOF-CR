Data Availability Statement

“S1”: Sentinel-1 data (VV and VH polarizations) used to assist with cloud removal.

“S2_cloudy”: Cloud-contaminated Sentinel-2 imagery

"S2_cloudfree": Reference cloud-free imagery used to calculate the loss.

"data.csv": Basis for the training, validation, and test set split, where "1" represents the training set, "2" represents the validation set, and "3" represents the test set.
